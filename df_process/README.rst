Common methods to import data from a polars dataframe.

Dataframe, specifically polars, are particularly efficient to transform
data in a massive way.

Datasource can be file or database query.

This module is used by ``file_df`` or ``db_process`` modules

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_
